# Cherry Studio

### AI assistant hub for all your models

Cherry Studio is a versatile desktop AI client that aggregates multiple AI providers into one beautiful interface. Manage API keys, compare responses, and build a personal knowledge base — all in one place.

<br>

---

## Features

| | |
|:---|:---|
| **Provider Hub** | One interface for OpenAI, Claude, Gemini, Groq, and 20+ more |
| **Knowledge Base** | Import documents to ground your AI conversations in your own data |
| **Translation Mode** | Side-by-side translation powered by your preferred AI model |
| **Topic Threads** | Organize conversations by project, client, or topic |
